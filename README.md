# Faz

一个从 [Kaku](https://github.com/tw93/Kaku) 修改而来的 macOS 终端。

## 与原版的区别

- **移除 AI 相关功能**：去掉了 AI 对话、代码生成、凭证管理与相关配置入口。
- **移除内置 SSH 客户端**：不再内置 SSH 协议栈与 SSH agent 转发，远程连接用窗格里系统的 `ssh`。`ssh_domains` / `ssh_backend` 等配置项一并删除。
- **移除 TLS 域**：跨机 attach 的 TLS 客户端与服务端配置整体移除。
- **保留基础多窗口操作**：多标签、多分屏、窗口与 pane 的常用管理能力不变。

## 文件传输（ZMODEM）

内置 ZMODEM 支持，ssh 会话中直接 `rz` / `sz` 收发文件，不再需要 zssh。

选择文件或目标目录时会弹出文件浏览器：

- **方向键导航**：上下移动、Enter 进入目录或选中文件、Backspace 返回上级。
- **`Ctrl-P` 输入路径**：进入输入行模式后可直接键入路径，支持 Tab 补全。
  - `Tab` 补全：唯一匹配直接补全；多个匹配先补到公共前缀，同时在输入行下方的独立面板里列出全部候选，按列排布、支持 `PageUp` / `PageDown` 翻页，底部显示当前范围与总数。
  - `←` / `→` 移动光标，`↑` / `↓` 翻历史，`Enter` 确认，`Esc` 退出输入行。
  - 支持 `~` 展开、相对路径（相对当前浏览目录）、绝对路径。
- **隐藏文件可见**：`.config` 这类路径可以直接浏览和补全。
- **记忆上次位置**：每个 pane 独立记住上次选择的位置，下次打开从那里开始。输入过的路径在同一次运行内可通过 `↑` / `↓` 回溯。
- **按 pane 独立工作**：选择器绘制在所属 pane 内，不占满整个 tab。广播模式下多个 pane 同时执行 `rz` 时，每个 pane 各自弹出一个选择器、各自独立完成，互不干扰；切到哪个 pane 就操作哪个选择器。

## tmux 集成

在窗格里运行 `tmux -CC` 会进入控制模式，Faz 为这个会话单独开一个窗口并接管 tmux 的 tab 与 pane：

- 窗口里的新建 tab 会同步创建 tmux window；分屏同样在 tmux 上下文里进行。
- tab 标题以 tmux 的 window 名为准，不受本地 `format-tab-title` 配置影响。
- **关闭窗口 = detach**：等价于在 tmux 里按 `c-b d`，客户端断开，tmux 会话仍在服务端运行。
- 运行 `tmux -CC` 的那个 pane 保持不动；多个 `tmux -CC` 各自拥有独立窗口。
